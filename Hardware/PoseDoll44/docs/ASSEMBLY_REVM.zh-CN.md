# Rev M 装配说明：先做成套部件，再连接全身

这份说明对应 `cad/revM/final_model.py` 构建出的 Manny / Quinn 总装。零件名、空间位置和逐件 STEP 以 `generated/revM/<角色>/manufacturing_manifest.json` 为准；同名旧版本不可混装。两款角色各有独立打印件和线束表，共用传感器板、区域板及关节结构族。

## 先认清三类零件

1. **你打印的件**：清单中带 `print` 项的 PLA 骨架、外壳、线夹。文件在各角色的 `print_candidates`。按 STL 原尺寸导入，单位 mm，不缩放。
2. **交给加工方的件**：铝合金轴系和连接件、POM 轴套、PEEK 摩擦片、薄金属压板、定制隔柱。按 STEP 与加工说明报价和预装。光滑轴颈是轴承工作面；普通全牙螺丝不能替代。
3. **购买或代装的件**：标准紧固件、碟簧、磁铁、PCBA、预压接线束。建议让贴片厂交付焊接完成的板，让线束加工方交付有标签且测过通断的成品线。SH 的 1 mm 接头不适合第一次接触硬件时自行徒手压接。

总装中近两千个 CAD 实体包括螺丝、焊接元件和尺寸包络，不是让你购买近两千种不同零件。传感器电子部件按 **39 块小板 + 2 块肩部大板** 采购成套 PCBA；区域板 6 块，电源分配板 1 块。

## 装配前准备

- 带公制内六角 1.5 / 2 / 2.5 mm 的螺丝刀；匹配 M2 / M3 螺母的小扳手、镊子、剪线钳。
- 游标卡尺、万用表；后续校准需要可核对角度的量角工具。扭矩验收用拉力计配已知力臂，不能把螺丝拧紧程度当成持姿扭矩读数。
- 准备浅盘，把左右侧、角色名、部件编号贴在袋子上。左右以人偶自身方向为准。
- 全部机械初装、插拔传感器线都在断电状态完成。电子仓最终装好并排除短路后才接外部低压电源。

**碟簧预紧筒由加工/装配方预装。** 腰胸候选预紧力达 1,656 N，手指压不住，也不应让新手靠试拧未知强度螺丝来压装。加工方应使用轴向夹具，检查金属止挡、螺纹啮合与装配高度，然后给出转动扭矩和回差记录。交给你的应是能够直接转动、安装的关节组件。

## 关节内部的共同结构

从固定侧到输出侧可以辨认出：固定金属轴承眼、POM 轴套、被固定侧限位的 PEEK 摩擦片、光滑轴颈及输出法兰、磨损/反力垫片、碟簧、键接金属止挡帽、轴端保持螺钉，以及独立的磁铁杯和传感器板托。

- 重力和手部操作力通过轴、法兰、轴套和框架传递；PCB 不承重。
- 磁铁必须为指定尺寸的**径向充磁**件，不能仅凭“圆形磁铁”采购。轴向充磁圆片不能代用。
- 磁铁杯通过键形面传角，螺钉负责保持；胶水不替代机械保持。
- `magnet_keeper` 是旋转侧的磁铁保持盖。线束不能绑在它、轴、转子或碟簧上。
- 软件的角度上限不是实体限位。当前 41 个测量轴都有负载侧机械限位；不要掰着磁铁杯撞限位。
- 腰、胸的六个关节是双摩擦面版本；不可拿早期 `compact_axis.py` 单独导出的旧模块代替最新总装中的组件。
- 高负载输出已有 D8 键形段，轴颈仍依各结构定义。D8 输出孔和 D6 轴套工作孔是不同位置，不是尺寸写错。

腰部与肘部的真实最终小总成有 [腰关节拆解图](../generated/revM/assembly_details/waist_pitch_exploded.png) 和 [肘关节拆解图](../generated/revM/assembly_details/elbow_l_flex_exploded.png)。图中间隔是分组展示距离，不能照图间距装配；实际尺寸以对应 STEP 为准。

## 建议的总装顺序

### 1. 逐个核对预装关节

对照查看器中的部件名称与 `mechanical_manifest/network_revM.json`，给每个关节贴上轴名，例如 `elbow_l.flex`。确认转动顺畅、有保持力，限位方向正确；先不插传感器线。磁铁盖、轴端螺钉和两侧保持件缺一个都不继续装入肢体。

传感器 PCB 应在两侧托座上平放，用绝缘压片固定板边。不要把螺钉拧到 PCB 弯曲。小板/大板的板厚和安装孔不同，不能互换。最新两种板均使用 SH6 接头。

### 2. 装左右腿和双臂

每条腿按髋屈伸 → 髋外展 → 大腿扭转 → 大腿梁 → 膝 → 小腿梁 → 踝两轴 → 脚托/前脚掌顺序核对连接。

每条手臂按肩带 → 肩屈伸 → 肩外展 → 上臂扭转 → 上臂梁 → 肘 → 前臂扭转 → 前臂梁 → 腕两轴 → 手部件核对连接。

紧固连接件时先保留工具通道：先放入被捕获的螺母，再装连接螺丝，最后才装 PCB 托、磁铁盖附近的服务件和外壳。对于被后一节遮挡的螺钉，在工作台上先组成该节的小总成，再连接上游。所有螺钉应按清单长度，不能以“更长更牢”为原则替换。

上臂每侧两组、前臂每侧一组 M2×20 螺钉与捕获螺母固定可拆外壳，共六组。先在独立臂段上放入后侧螺母，再从前侧装螺钉，之后才连接上下游关节；六组直线螺钉/螺母及刀杆通道单独检查。螺钉仅连接壳体凸台与骨架安装耳，不能任意拧到壳体变形。

轴向保持螺钉不用于每天调整手感。手感通过规定的碟簧高度/垫片组合及摩擦片来确定；实际扭矩超出验收窗口时返工该组件，不用任意松开保持螺钉。

### 3. 装骨盆、腰、胸和颈头

先把骨盆内部框架与腰部轴系连接，再装胸部输入框、胸部三轴、胸框和颈头组件。颈梁有绕开肩部运动空间的路径，不能改成看起来更短的直杆。

骨盆没有外部支架接口的强制约束，也没有三颗用于测世界朝向的传感器。软件始终声明 `pelvis.yaw/pitch/roll` 为固定参考。腰部运动从 `waist.*` 开始测量；髋部运动由左右 `thigh_*` 测量。

### 4. 装电子仓

每组背部载板先装好被捕获的螺母，再固定到骨盆/胸框。区域 PCB 靠四角的硅胶垫及壳体夹持，不要自行在 PCB 上钻孔。

从人偶自身左到右，胸部仓是 N3 / N2 / N4，骨盆仓是 N5 / N1 / N6。N1 是 USB 网关，后面另有独立电源分配仓。盖上的指示灯孔用于观察电源状态。

电源板四个 M2 固定点使用图示的绝缘垫片；插座后方的壳体挡块承受插拔力。不要省略背盖或只让焊脚承受插头推力。底部直流插座和 USB 出口保持可拔插。

### 5. 装线束，最后装壳

按[线束说明](WIRING_REVM.zh-CN.md)逐根连接。先装稳定肢段的线夹和硅胶保护，再布置关节外侧的松弛 U 形线段。转到各轴两端逐一确认没有拉紧、缠轴和夹线，之后才装稳定部位的壳。

头、胸前、上臂、前臂、手、大腿前侧、小腿和脚部外壳为分段可拆件；肩带、肘、腕、腰、髋、膝、颈等活动空间保持开放。大腿后侧、小腿后上段等容易相互挤压的部位也留空。缺少连续皮肤是有意的，不需要自行补软胶或硬片。

## 阶段性验收

完整 CAD 已按两款全身配置设计；实物仍按下面顺序放行，避免一开始同时制造两整套：

1. 一套高负载腰部双摩擦面关节：装配高度、持姿扭矩、起动阻力、30 分钟下垂和重复摆动。
2. 一组传感器小板 + 一个区域板：磁场诊断、角度重复性、最长线束、温升和断线状态。
3. 一条完整手臂、一条完整腿：框架刚度、层间强度、外壳/线束干涉、紧固件松动。
4. 一款全身后再复制另一款：新增质量后的持姿、坐/躺动作、41 轴同步、全身校准与 UE 姿态对应。

螺丝和板件松动、打印裂纹、异常温升、线束被夹或传感器磁场故障都应记录并修正。数字碰撞通过不能代替这些检查。记录表、量化阈值与校准步骤见[验证与校准](BUILD_AND_CALIBRATE_REVM.zh-CN.md)。
