# Rev M 制造与检验说明

本文件是两款完整原型的制造约束，配合各角色的 `manufacturing_manifest.json`、逐件 STEP 和采购分类表使用。**交付状态为数字原型候选，不是已完成实物鉴定的量产图纸。** 加工方应先反馈可加工性、检验方案和报价；不要直接把整套文件当作已批准订单。

## 制作方式

| 类别 | 制作方式 | 接收条件 |
|---|---|---|
| `frame`、`shell` | 0.4 mm 喷嘴、PLA 原型打印 | 使用 `print_candidates` 中已摆放的 STL；不缩放 |
| `aluminum_7075` | 7075-T6 / T651 精密加工 | 材料证明，精加工轴颈和配合孔；不以打印塑料替代 |
| `aluminum` | 6061-T6 精密加工 | 精加工摩擦面、键形配合与螺纹 |
| `pom` | POM-C 车/铣轴套 | 区分自由尺寸与装配压缩尺寸；压入后检验工作内孔 |
| `peek` | 未填充 PEEK 摩擦片 | 按 STEP 切出止转耳；厚度、平面度、干摩擦实测 |
| `steel_17_4` | 17-4PH，H900，磨削接触面 | 热处理证明，去毛刺；不得用普通镀锌垫片代替 |
| `brass` 隔柱、键件 | 黄铜精密加工 | 定制高度与小螺纹；不要按最近的整数长度替换 |
| `nylon` 压片 | PA12 / 尼龙板切削或合适精度的 PA12 工艺 | 0.8 mm 等薄片不列入 PLA 打印清单；边缘夹板应平整 |
| `silicone` 垫片 | 硅胶片模切 | CAD 是安装后的厚度；线夹垫自由厚 0.5 mm、装后约 0.4 mm |
| 碟簧、标准螺丝、磁铁、止推垫圈 | 标准件采购 | 按物料表规格及尺寸包络检查，不能仅凭螺纹直径替换 |
| 电子件 | 成套贴装 PCBA 和预压接线束 | 按原生 KiCad 工程及线束工单，交付通断与上电记录 |

`metal`、`spring` 等 CAD 色彩分类不都是一个采购类别。例如 `spring_seat` 是定制座，`disc_spring` 才是采购碟簧。采购分类表会区分两者。模型中的 PCB 电阻、电容与连接器不要再按机械零件重复采购。

胸框、颈部转接框等复杂 7075 件当前按整体加工几何交付，需要多面装夹/多轴加工，局部可由线切割、电火花或精密孔加工配合完成。它们不是普通桌面打印件，也没有声称三轴铣床一次装夹可做完。加工方如要求拆件，必须先给出拆分和连接方案，再回到 CAD 验证；不得现场自行锯开、焊接或更换材料。早期注释中的“machining split pending”不代表当前文件已经包含拆分件。

## A1 mini 打印安排

每款有 187 个独立打印候选文件，包括重复实例。全部名义外包络都可放入 180 × 180 × 180 mm，检查另给 X/Y 各留 3 mm 裙边空间。这个结果只证明包络能放入，未执行 Bambu Studio 实际切片，也未验证支撑、局部翘曲和打印强度。

- 导入后执行切片器的“落到平台”与居中，不缩放；少量工艺圆筋会使 STL 最低点略低于名义 Z=0，记录中保留实际最小坐标。
- 初始层高 0.20 mm，喷嘴 0.4 mm；骨架 6 道墙、40% 填充，壳体 6 道墙、15% 填充。孔位、细壁和薄保持盖应在切片预览确认确实形成连续路径。
- 两条约 23 cm 的小腿梁以三维对角方向放置，不能平放后强行缩小。导出的 STL 已变换姿态；清单 `print` 项记录旋转、平移、包络和支撑复核要求。
- Manny 右小腿梁当前含 3 mm 裙边的最大名义尺寸约 179.55 mm，距 180 mm 只余约 0.45 mm；这是最紧的一件。实际切片若支撑越界，先调整朝向/支撑或借用更大热床，不能缩短骨长。
- 斜放长梁需要支撑；仅包络通过不能保证切片器生成的支撑仍留在热床内。首件切片应由设计端复查支撑足迹和层间受力，不要求你猜。
- 测角板、轴颈、摩擦面、弹簧座、配合孔不是靠“打印高精度”解决。打印件不承担 1,656 N 关节轴向预紧。
- 打印孔允许后续按实际螺钉/螺母检验和修整；工作轴孔由金属座和加工轴套定义。第一次只做一个关节和一根受力梁的工艺验证。
- 不把整套文件一口气排成打印任务。先通过高负载关节与梁的阶段测试，再安排其余部件。

打印件使用的是暂定 PLA 工艺。打印朝向、不同品牌材料、温度和层间结合会改变强度；CAD 与填充百分比不能提供额定负载。下面的载荷验收先于全身使用。

## 关键尺寸与公差候选

STEP 中的螺纹以名义圆柱/底孔表示，并未建螺旋牙。加工方必须按螺纹标注攻牙，不能把 1.6 / 2.5 mm 底孔当作已经完成的 M2 / M3 内螺纹。常规公制粗牙为 M2×0.4、M3×0.5；金属内螺纹 6H、外螺纹 6g，精度由检验确认。

| 功能 | 原型加工与检验要求 |
|---|---|
| 光滑 D4 / D6 轴颈 | 名义尺寸 0 / −0.01 mm；Ra ≤0.8 μm，去掉毛刺；工作面不可带螺纹 |
| 捕获式 D6 轴套工作孔 | Ø6.06 +0.02 / 0 mm；装后转动验收；法兰名义轴向游隙 0.15 mm |
| 捕获式 D4 轴套工作孔 | Ø4.06 +0.02 / 0 mm；具体法兰和座以当前 STEP 为准；不能套用 D6 法兰尺寸 |
| 16 处肩部压入式轴套 | 金属孔名义 +0.000…+0.010 mm；POM 自由外径比名义大 0.025…0.035 mm；装后精修 Ø4.04 或 Ø6.04 工作孔 +0.02 / 0 mm |
| 压入式轴套保持 | 10 N 轴向拉出验收目标；检查温度变化和重复摆动后是否松脱。这是验收要求，尚无测得通过值 |
| 轴向堆叠关键面 | 加工候选 ±0.02 mm，接触面平面度 ≤0.02 mm；最终按实际碟簧与摩擦片测厚选垫 |
| PEEK 摩擦片 | 名义厚度见 STEP；厚度候选 ±0.02 mm；无毛刺、无油，摩擦面配合件 Ra 0.8…1.6 μm 候选，最终由持姿测试决定 |
| D 形传角配合 | 当前模型一般留 0.05 mm 单侧候选间隙；加工后逐对检验回差，不用胶填充代替键面受力 |
| 传感器安装 | 芯片对磁铁的名义面间距 1.5 mm；装后目标 1.5 ±0.2 mm，同轴偏心目标 ≤0.15 mm；最终以磁场诊断和测角误差验收 |
| 小传感器板 | 12 ×10 mm，板厚 1.0 mm，要求供方确认 ±0.1 mm；39 块，板边夹持 |
| 大传感器板 | 18 ×20 mm，板厚 1.6 mm；2 块，仅肩外展；SH6 插座方向与小板工程分别确认 |
| 区域板 / 电源板 | 40 ×86 ×1.2 mm / 40 ×70 ×1.6 mm；壳体尺寸不可按旧版板形加工 |

每款 6 个打印件的名义几何有零厚度相切边，STL 已用半径 0.10 mm 的小圆筋闭合，并附 `_print_process.step` 工艺实体。它们位于一侧前臂、四片前脚掌盖和电源背盖；变化记录在 `verification/revM_print_mesh_export.json`，整机干涉及质量另行回算。打印以这些 STL 为准；不要把名义 STEP 重新粗糙网格化后替换它们。此处理只解决网格与几何有效性，细部能否形成连续挤出线仍要切片复查。

这些是原型拟定的加工要求，不是从打印机宣传精度推导出的保证值。轴套自由态尺寸覆盖 CAD 中的安装态外径；不要重复叠加补偿。传感器板托需要随实测 PCB 厚度选择薄绝缘垫，不能通过拧弯 PCB 来补厚度。

## 关节预装与防松

腰、胸关节使用两处 PEEK 摩擦面。六个碟簧分成两个方向相反的组，每组三片同向套叠；不要误装成六片全部同向。名义 1,656 N 是两组串联后的轴向力，不再乘以二。所有材料和结构都以最终整机导出件为准，历史 `components/H6P4` 不能替代当前腰部版本。

轴向保持螺钉必须在轴向夹具支撑下装配，确认止挡帽坐到金属端面、螺钉没有触底，并验证完整啮合长度。装配方按力—位移/堆叠高度控制预紧，再测旋转扭矩；**没有给新手一个可盲拧的通用拧紧扭矩。** 预装关节应随附每轴的起动/运行扭矩、回差和 30 分钟下垂记录。

全金属小螺纹的可拆防松选用少量 LOCTITE 222 候选，由加工方在塑料和摩擦片装入前施用、清除溢胶并充分固化；不得让胶进入轴套、PEEK 摩擦面、传感器或磁铁间隙。尼龙件、塑料附近螺母不涂这种厌氧胶，采用合适的预涂尼龙防松螺纹或机械保持，并验证拆装次数。胶与表面处理的相容性先做小样。[Henkel 使用范围与技术资料](https://datasheets.tdx.henkel.com/LOCTITE-222-en_GL.pdf)

磁铁按 Ø6×2.5 mm、径向充磁、相容的 AS5000-MD6H-2 候选采购并检验；外径、厚度和磁场以到货记录确认。杯内薄胶层只负责防止磁铁打滑，外侧保持盖负责防脱。胶种选 3M Scotch-Weld DP460 Off-White 双组分环氧作为原型候选，由预装方按配比和批次技术资料室温固化，先做镀镍磁铁/铝杯样件的相容性、收缩和滑移测试。不要靠高温加速固化，也不要用瞬干胶临时代替后省略测试。该胶用于防转，不能据产品粘接强度推算整个人偶的结构强度。[3M 产品与技术资料](https://www.3m.com.cn/3M/zh_CN/p/d/b40066439/)

## PCB 交付给贴片方的要求

四套自包含 KiCad 工程位于 `generated/revM/electronics`，均附 ERC、DRC 和原理图/PCB 一致性结果。`fabrication_candidate` 中的 Gerber、钻孔文件供工程审查，不能单凭“零 DRC”跳过制板工艺确认。

区域板是四层 1.2 mm。USB 差分阻抗目标 90 Ω，要求制板方给出实际叠层/铜厚/阻抗计算；电源芯片散热焊盘中的过孔要求填孔并封盖，或经复核后修改工艺。未确认叠层时，不把当前走线宽度当作受控阻抗已经达标。

两种传感器板背面的 C2 指定 Murata GRM219R61E106KA12D，限制高度已进入机械模型；不可用同容值但更厚的 0805 电容直接代料。其他封装匹配的替代器件也要核对电压、容量降额、容差、引脚和最大外形。

区域/电源板原生导出的 `board_native.step` 尚缺少 5 / 1 个供应商三维模型；完整人偶 CAD 已补入相应最大外形包络。裸 `board_native.step` 不是完整 PCBA 的干涉依据，电子元件也不是可以 CNC 加工的实体。

供电为外置 **稳压 5 V、至少 3 A、带短路保护**的适配器；5.5/2.1 mm 插头，中心正。仅接低压输出，不制作市电部分。3 A 保险丝不是对限流 3 A 电源“必定熔断”的保证；电源自身短路保护仍须存在。USB VBUS 不给人偶电源母线供电。

## 量化实物验收入口

参考 `verification/revM_load_work.json` 的每轴重力需求。原型目标为实测保持扭矩 ≥该轴预算重力需求的 1.5 倍；运行阻力不宜比设计名义扭矩高 20% 以上，起动/运行阻力比目标 ≤1.5。它们是本项目的验收目标，不是已验证性能。

首件装配方需要验证高负载保持螺钉/螺纹、轴的键槽与横孔、反力垫片、小框架转角及 PLA 层间承载。简化强度筛查不覆盖应力集中、跌落、疲劳和长期蠕变，不能给整机贴上额定负载。按[测试与校准步骤](BUILD_AND_CALIBRATE_REVM.zh-CN.md)分阶段填写记录，失败的部件回到设计端修改。
