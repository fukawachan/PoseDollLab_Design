## Rev B 识别和孔位

H1-001 为 110×74×6 mm，五排孔。左下为 6 mm 大切角、右上为 3 mm 小切角；从下到上 M2、M3、M4、M6、POM。每行五个孔的数值见 [孔位图](../generated/drawings/coupon_map.svg)，不要再使用旧版“统一加 0.1 mm”的读法。

H1-002 为 86×40×8 mm，同样有两个切角。上排 M3 螺母槽对边 5.8 / 6.0 / 6.2 / 6.4 mm、深 2.8 mm；下排磁铁槽直径 6.0 / 6.2 / 6.4 / 6.6 mm、深 2.6 mm。

H1-003 从左到右为 1 / 1.5 / 2 / 2.5 / 3 mm 的厚度片；设计不变。0.10 mm 层高用于保留这些半毫米厚度及 H1-002 的槽深。

## 后续如何使用

设计端会先确定实际五金和装配测试包，再说明哪些试片需要打印。届时分别导入对应文件，检查孔未封住、方向正确，不自动缩放。

螺丝孔直接用实际 M2/M3/M4/M6 螺丝轻推，不能旋拧着切入塑料。POM 座用实际轴套，螺母和磁铁槽用对应实物。不同配合用途分别判断，不需要额外的四根测试圆棒。

先记录冷却后的原始结果，不钻、磨、涂胶后当原始数据。记录方法保存在 [测量表](MEASUREMENT_RECORD.zh-CN.md)。这张试片不能代替长孔、完整装配、定位和承载验证。
