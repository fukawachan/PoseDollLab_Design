# Rev G · 分段硬壳，活动区裸露

按用户最新决定：**形状稳定的独立刚性部位可以包壳；会因运动产生外形变化的区域不包壳，直接露出机械骨架。** 此规则适用于 Manny 和 Quinn，替代上一轮的柔性连接、浮动肩盖及重叠活动壳片方案。

目标仍是让人偶具有可辨认的人体比例和方便握持的四肢主体。活动区的开口是有意保留的结构，不是等待补齐软皮的缺口。当前为设计研究，尚未制造放行。

## 身体各部位怎样处理

| 部位 | 当前覆盖决定 | 壳体边界 |
|---|---|---|
| 头部主体 | 可用硬壳 | 颈部转轴保持裸露 |
| 上臂、前臂主体 | 保留可拆的分段硬壳 | 肩根、肘窝、腕部和前臂旋转连接处开口 |
| 大腿、小腿主体 | 设计分段硬壳 | 髋、膝、踝周围退让，不跨接转轴 |
| 手掌及脚的刚性节段 | 可用硬壳 | 腕、踝和前脚掌弯曲轴裸露 |
| 胸腔、骨盆的中央刚性框架 | 仅在确认稳定的局部设置小壳 | 每片只随一个刚性节段运动，不能默认整片胸背或骨盆都可封闭 |
| 肩带、肩胛活动区、肩根、腋下 | 裸露 | 不设计硬壳、软皮或浮动肩盖 |
| 颈、腰腹、腹股沟 | 裸露 | 保留相邻节段的旋转和让位空间 |
| 肘、膝、腕、踝及轴向旋转连接区 | 裸露 | 壳边按运动范围修剪，必要时延伸到邻近肢体主体，不能只留一条细缝 |

这里的“稳定”指属于同一个机械刚性节段，并非假设真实人体肌肉完全不变形。例如前臂主体仍可以有外壳，但若内部旋转使两部分相对运动，外壳也必须分开，不能把它们锁在一起。

因此，肢体中段可以保持人形轮廓，内侧需要被挤压或让位的部分则可以开窗、截短。机械功能与完整动作范围决定壳边，不能为了外形完整把关节重新封住。

## 对原 44 轴设计的影响

各角色体格比例、轴 ID、轴序、轴向和运动范围继续保留。肩带每侧的前伸／后收、抬高／下压两轴也保留；当前尺寸的实体肩带仍需完成，不会因为外露而自动视为已验证。

约 90.8 cm、1:2 仍只是封装研究候选，本次决定没有再次放大人偶。肩部前伸时的肩中心位移约 44.5 mm（Manny）和 38.1 mm（Quinn），这片运动空间现在保留开放，不再设计柔性件跨接。

[肩部动作查看页](../generated/revG/Human_Form_and_Shoulder_Review.html) 中的完整 UE 体表只用于观察比例与动作，不是实际硬壳覆盖范围。实体的肩带和周边活动区将裸露。

## 已落到局部 CAD 的修改

已有上臂、前臂分体壳继续保留，并进一步切退肘窝闭合侧的边缘。新的让位面截距为 24 mm、斜率为 2.5，具体位置由局部坐标定义；这不是要求用户自己测量的装配尺寸。

两款 STEP 均随脚本重建，指定弯肘样本与壳片实体检查结果以 [当前检查报告](../verification/REVG_REPORT.zh-CN.md) 为准。检查没有覆盖完整手臂所有转轴、制造公差、载荷和实际操作手感，不能据此把全身标为已通过。

壳体扣合、固定螺钉、倒圆和线束仍需细化；当前新 PCB 和部分传动件也只是占位。其余部位的表格是完整人偶的设计约束，不代表对应 CAD 已全部完成。

## 接下来的结构验证

1. 裸机构先满足全部轴的目标范围与组合姿势，再装上稳定节段硬壳复核；没有第三步“加软皮”的验收要求。
2. 肩带检查前伸、后收、耸肩与举臂、抱臂等组合；肘、膝和髋检查最大弯曲时壳边是否碰撞。
3. 按带壳后的重量与抓握位置核算持姿力矩、操作力和线束恢复力。
4. 裸露区域整理走线、处理接触边缘并留出手指操作空间；这些局部处理不能变成覆盖活动区的外壳。
5. 保留单节段可拆壳、传感器可维护性与原 44 轴读数校准。

结构化规则保存在 [shell_coverage_revG.json](../mechanical_manifest/shell_coverage_revG.json)。当前不用打印、测量或采购。整机机械设计、颈部位置误差和 Quinn 的独立 UE 适配等未完成项继续登记。
