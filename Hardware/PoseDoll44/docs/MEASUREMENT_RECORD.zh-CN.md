**当前不用填写，也不用购买工具或测试件。** 用户要求先完成设计，之后再进行实测。以下保留为未来模板，所有结果目前都是“未测”；设计继续使用 [暂定参数](DESIGN_BASIS.zh-CN.md)。

最终测试物、零件版本和需要测的项目由设计端在装配测试包中写明。孔里装什么，就用那个实际零件；取消额外准备四根圆棒的要求。

## 测什么，以及为什么

打印孔和实际五金的尺寸可能有偏差。用实际装配件试配，是为了选择可装配的尺寸并发现松动；不要求你自行确定公差。

螺丝通孔需要允许穿过，轴套座需要保持轴套，磁铁座还需要定心及防自转。所以“紧配”不总是更好，“能滑动”也不自动代表全部接口合格。后续整关节的转动、持姿和耐久测试另行安排。

## 以后怎样记录

### 螺丝通孔

同一行 A～E 用同一颗螺丝。孔冷却后，从顶面轻推，不旋拧、不敲、不磨合。最终处于孔中的光杆/螺纹段需要能穿过 6 mm 厚度，安装时要经过孔的螺纹段也需要能够直接通过。

| 填写值 | 现象 |
|---|---|
| 进不去 | 轻推不能穿过；只进端头或卡在出口也算，注明位置 |
| 紧配 | 能直接穿过并拔出，但持续有明显阻力 |
| 能滑动 | 很小的手力就能来回移动，不要求靠自重掉下 |
| 明显晃动 | 孔口可见相对松动；不用长螺栓远端撬孔 |
| 未测 | 没有对应实物、未尝试，或试片有缺陷 |

通孔有间隙不自动不合格，“紧配”也不是目标。若有阻力同时又松动，备注两种现象。保留第一次结果，不靠旋拧切出螺纹再记为“能通过”。

### 轴套、螺母与磁铁

- POM 轴套：记录装入深度和“进不去 / 能轻压装入 / 能自由滑入 / 明显晃动 / 未测”。两面保持可接近，轻试而不硬压卡死；只试入口就只记录入口。6 mm 长轴套不要求像长螺丝一样从另一端伸出。
- M3 螺母：记录“不能放到底 / 能到底且基本不转 / 能到底但明显转动 / 未测”。普通螺母候选对边 5.5、厚约 2.4 mm，不能混用法兰或尼龙锁紧螺母；只用手轻试。
- 磁铁：记录“不能平放到底 / 能到底且无明显侧隙 / 能到底但明显侧向松动 / 未测”。只使用最终选定的磁铁，不另买不明磁铁填表。

黄铜套外圆与 POM 内孔之间的转动配合，以后直接使用这两个装配件检查，不能由打印孔试片推断。
