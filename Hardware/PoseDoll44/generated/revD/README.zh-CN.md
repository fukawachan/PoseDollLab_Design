# Rev D 进行中的机构研究

当前仅有三规格紧凑关节的首轮 CAD，不是全身等比例模型，也不是打印放行包。

- 旋转动静件样本无穿插，但传感器托架的圆杆截面与垫片存在未修复相交，见 [逐件结果](../../verification/revD_compact_modules.json)。
- 初轮质量约 S 71 g / M 90 g / L 125 g，不能据此沿用 Rev C 的 2.01 kg 全身质量预算。
- 用户指出的体格比例要求优先处理：先固定按 Manny 统一缩放的关节中心、肢体比例和运动误差目标，再决定这些机构能否使用及如何安装。
- 当前没有完成整机安装、完整负载重算或电子节点设计。无需用户打印或测量。
