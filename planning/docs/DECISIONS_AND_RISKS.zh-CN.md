# 决策、风险与尚未冻结的内容

## 架构已定、制造参数待定

已定：完整44轴、6区域+1网关、有线被动关节、同轴绝对测角为基线、独立实体profile、不覆盖虚拟测试、CLI-first、先全身布局再分阶段制造。

待定：精确高度和比例、每个模块轴径/摩擦材料/扭矩、磁铁与PCB安装尺寸、最终机械限位、传感器具体采购后缀、MCU具体模块、收发器/稳压器/保护器件、连接器料号和针脚、线径、PCB层数、外接电源额定电流、实际成本。这些不是让用户自己填空，而是 Codex 在对应设计阶段必须解决的任务。

## 核心风险及前置试验

| 风险 | 为什么会影响体验 | 处理与退出条件 |
|---|---|---|
| 关节撑不住或太难掰 | 读数准确但无法舒适摆姿势 | 负载与手部操作力一起预算，H1/H3 实测 |
| 密集磁铁串扰 | 另一个关节运动导致本轴假运动 | H2 密集组件及整机靠近姿势实测；先改间距/位置，不用单一零点掩盖 |
| 串联三轴不好操作 | 数学可表示但实体轴接近重合 | H0/H2 关键姿势与轴顺序评估，必要时版本化更改机械布局 |
| 线束拖拽或疲劳 | 姿势回弹、端口断续、焊点断裂 | 把真实线束加入 CAD/扭矩/循环试验，限定行程并应力释放 |
| FDM 配合与长期变形 | 关节松紧变化、定位不稳定 | 配合试片、金属预紧路径、可换摩擦件和循环持姿试验 |
| SPI 多支路信号质量 | 单轴台架通过、全区域随机错误 | 驱动/电容/最长线审核；缓冲/分组/端口隔离按需要设计 |
| CAN 被画成星形 | 电气可靠性依赖偶然线长 | 明确干线/终端/短支路和组装标识，不把外形拓扑当电气拓扑 |
| 电源压降/USB反灌 | 重启、损坏电脑或区域器件 | 完整功耗与保护电路，受控初次通电，未经确认不并联电源 |
| UE 仍用虚拟校准 | 实体角度系统性错误却看似连通 | 新配置选择、设备身份和哈希握手，旧模拟器保持回归 |
| 自动工具产生伪通过 | 只有有效文件，没有有效硬件 | 原始证据、独立复核、not_run 与实测通过分离 |

## 不采用的捷径

不把十几个 IMU 贴在普通娃娃上作为本版基线；不把一颗三维磁场传感器默认等同于任意球关节三轴测量；不使用电位器读数精度/寿命未经评估的替代；不把44根I²C长线与多路开关简单堆叠作为整机方案；不将全部几何一次打印成不可维修的人偶；不为了“AI全自动”而自动下单和远程打印。

若 AS5048A 的供货、体积或磁场效果不满足目标，可以更换编码器或局部关节结构，但仍需真实提供该轴的绝对测量、诊断和经验证的机械变换。替换不得偷偷减少目标轴数或伪造与原先相同的精度。

## 精度边界

最终角色误差还包括连杆弹性、机械背隙、磁铁定位、安装基准、角度测量、身体比例映射与用户摆姿势误差。单颗芯片的位数不能覆盖这些因素。手的位置误差也不能只由一个关节角度误差简单代表；肩/肘误差会沿长链累计。完整手部位置精度需在目标模型、测量空间和姿势集确定后单独定义。
